## 🚀 Getting Started

To run this project locally:

1. Clone the repository

```bash
git clone https://github.com/sricharangoud/Personal_Portfolio.git
```

2. Open the project folder

```bash
cd Personal_Portfolio
```

3. Open `index.html` in your browser.
